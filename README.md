## 🔐 About

Personal cybersecurity portfolio built with React, TypeScript, and Vite. Features a hacker-themed terminal UI, interactive CTF challenges, and a live AI-powered chatbot.

**Owner:** Aboubacar Sidick Meite — M.S. Cybersecurity Graduate (May 2026), Montclair State University

---

## ✨ Features

- 🖥️ **Live Terminal** — fully interactive bash-like terminal
- 🏴 **13 CTF Challenges** — crypto, web, network, forensics
- 🤖 **AI Chatbot** — answers questions about skills & background
- 🔐 **Projects Showcase** — CipherLab, CryptoMath, FileIntegrityWeb & more
- 🌙 **Hacker Aesthetic** — glitch effects, matrix animations, neon UI
- 📱 **Fully Responsive** — mobile & desktop

---

## 🚀 Run Locally

```bash
git clone https://github.com/ApollonASM8977/HackerPortfolio.git
cd HackerPortfolio
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173)
